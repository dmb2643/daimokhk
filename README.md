# даймохк

## Full-stack приложение - доска объявлений. 

## Реализовано:
  подготовлены локальное окружение PostgreSQL, первая миграция схемы и команды task. HTTP сервер и эндпоинт GET /health, и тест эндпоинта

## Необходимые инструменты для запуска: 
  - docker
  - docker compose
  - go 1.27+ 
  - goose 
  - task

## Запуск:
  ### 1. подготовить .env файл:
  ``` 
    cp .env.example .env
  ```
  *задать локальный пароль и проверить согласованность имени пользователя, базы и параметров подключения goose*
  ### 2. запуск PostgreSQL:
  ```
  task db:up
  ```
  ### 3. проверить работу PostgreSQL:
  ```
  task db:status
  ```
  ### 4. миграция базы данных:
  *применить миграцию:*
  ```
  task migrate:up
  ```
  ### 5. проверяка состояний миграций:
  ```
  task migrate:status
  ```
  ### 6. Запуск сервера:
  ```
  task run
  ```
 ## Пояснения:
  - Все команды выполняются из корня проекта
  - .env содержит локальные настройки и не добавляется в Git
  - После проверок ожидаются healthy у базы и дата применения у миграции вместо Pending

## Тестирование:
```
task test
```
## Остановка PostgreSQL:
   ```
  task db:stop
  ```
